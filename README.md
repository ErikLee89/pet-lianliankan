# 宠物连连看

浏览器版连连看游戏。下载项目后，用浏览器打开 `index.html` 即可游玩。

## 功能

- 初级、中级、高级、特高四档难度，棋盘随难度扩大。
- 11 种关卡布局，支持提示、洗牌、奖励和惩罚。
- 消除等待期间可以继续点选，选中状态随牌移动。
- 平滑宠物图标、动作音效及17首背景音乐，支持切歌。背景音乐采用 64 kbps MP3。
- 自动保存本局进度，刷新或重新打开后可继续，恢复后先暂停。返回菜单保留进度；开始新游戏前确认覆盖旧进度。本局结束后保留待保存成绩，刷新后可恢复结算界面，保存或跳过后清除。
- 正式榜与练习榜按难度各保留前 20 名，高亮本次入榜成绩；旧版成绩保留在历史成绩分类。非第一关开局、跳关或使用秘籍计为练习局。
- 个人最佳按名字和难度记录，仅统计已保存的正式成绩，结算时显示纪录变化。
- 音乐和音效可分别调节音量，并记住音量设置。
- 保存成绩后手动返回菜单，也可沿用难度、图案和起始关卡再玩一局。
- 进度和成绩保存在当前浏览器的 localStorage 中，不跨设备同步。

## 操作

点击两张相同图案，连线转折不超过两次即可消除。右键取消选中，P 或回车暂停/继续。跳关和秘籍收在“练习设置”中，起始关卡在菜单的“练习设置”中选择。消除连线固定停留 300 毫秒，不受声音开关影响。

## 文件

- `index.html`：游戏页面和逻辑。
- `assets/`：图标、音乐和音效。
- `CHANGELOG.md`：更新记录。
