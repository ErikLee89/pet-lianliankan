# 宠物连连看

浏览器版连连看游戏。下载项目后，用浏览器打开 `index.html` 即可游玩。

## 功能

- 初级、中级、高级、特高四档难度，棋盘随难度扩大。
- 11 种关卡布局，支持提示、洗牌、奖励和惩罚。
- 消除等待期间可以继续点选，选中状态随牌移动。
- 平滑宠物图标、动作音效及17首背景音乐，支持切歌。
- 排行榜保存在当前浏览器的 localStorage 中。

## 操作

点击两张相同图案，连线转折不超过两次即可消除。右键取消选中，P 或回车暂停/继续。

## 文件

- `index.html`：游戏页面和逻辑。
- `assets/`：图标、音乐和音效。
- `docs/`：原版规则核对记录。
